# 중국산프리 네이버 블로그 글 작성 가이드

매일 상품 1개로 네이버 블로그 상품 추천 글을 만들어 **복붙 페이지(Artifact) 1개 + 썸네일 이미지 1장**으로 전달한다.
네이버 업로드는 사람이 직접 한다. (Claude의 브라우저 도구는 네이버 접속이 차단돼 있으니 시도하지 않는다.)

## 목표
검색으로 들어온 사람이 중국산프리 홈페이지(https://joongfree.com)로 넘어가게 하는 것. 구매 링크 클릭은 그 다음.

## 1. 상품 고르기
- 데이터: 레포 `products.json` (`show: true`인 상품만).
- 제외: `buyUrl`이 `https://link.coupang.com/a/`로 시작하지 않는 상품(파트너스 링크 아님), `ingredientImageFile`이 없는 상품.
- 중복 금지: Artifact 도구 `action: "list"`(limit 50)로 기존 복붙 페이지 제목을 확인한다. 제목이 `블로그 #<id> ...` 형식이니 이미 쓴 id는 건너뛴다.
- 우선순위: 지금 시기에 검색이 많은 제품군(제철, 명절, 김장 등 시즌 이슈) → `curation`(무첨가/저가공/저당)이 있는 상품 → 최근 등록(`checkDate`) 상품.
- 같은 카테고리가 며칠 연속되지 않게 돌린다.

## 2. 사실 확인 (가장 중요)
- 원재료 이미지(`DB_img/Source/<ingredientImageFile>`)를 Read로 직접 열어서 원재료명, 원산지, 내용량, 제조원 등을 라벨에 적힌 그대로 옮긴다.
- 라벨에 없는 내용은 쓰지 않는다. 맛 후기, 먹어본 척, 건강 효능, 질병 관련 표현, "100% 안전" 같은 단정 금지.
- 타 브랜드 비방 금지, 등록 상품 개수 언급 금지, 원산지 둔갑 이슈 언급 금지.
- 원산지 정리 아래에 `※ 제품 뒷면 표기 기준 (YYYY년 M월 확인)`을 넣는다. (`checkDate` 기준)

## 3. 제목·키워드·태그
- 메인 키워드 구조: "[제품군] + 중국산 없는 / 국산 원료 / 원산지". 예: 중국산 없는 고춧가루, 국산 원료 떡볶이 떡
- 제목: 메인 키워드를 맨 앞에, 25~35자. 예: `국산 고춧가루 추천｜중국산 없는 영양 고춧가루, 원재료 직접 확인했어요`
- 본문에 메인 키워드 3~5회 자연스럽게, 소제목에 1회.
- 태그 10개, `#태그 #태그` 형식 한 줄. 메인 키워드, 제품군, 브랜드명, 중국산프리, 원산지 관련 표현.

## 4. 본문 서식 (네이버 스마트에디터 복붙 기준)
`blog/tools/example_body.html`이 기준 예시다. 구조와 인라인 스타일을 그대로 따르고 내용만 바꾼다.
- 네이버는 붙여넣을 때 문단 여백(margin)을 무시한다. 간격은 빈 줄 `<p>&nbsp;</p>`로만 만든다.
  - 소제목 앞 빈 줄 2개, 소제목 뒤 1개, 문단 묶음 사이 1개.
- 한 줄에 한 문장. 짧게. 해요체, 중국산프리가 직접 원재료를 확인해서 알려주는 친근한 톤. AI 말투, 이모지 남발 금지.
- 핵심 문장 1개만 초록(#20AF51) 굵게.
- 이미지는 `<img data-repo="레포 경로">`로만 적는다. (빌드 때 jsDelivr 주소로 바뀜)
- 순서:
  1. 대가성 문구 (13px 회색): 이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
  2. 도입 (공감 → 결론 먼저)
  3. 핵심 문장 (초록 굵게)
  4. 제품 기본 정보 (목록)
  5. 원재료·원산지 확인 (원재료 이미지 → 목록 → 확인 기준 문구 → 짧은 설명)
  6. 이런 분께 맞아요 (사실 기반 목록 4개)
  7. [제품군] 원산지, 이것만 보세요 (원산지 표시 보는 팁)
  8. 원산지 확인, 매번 하기 번거롭다면 (중국산프리 연결)
  9. 홈페이지 버튼 `brand/homepage_button_s.png` → https://joongfree.com
  10. 구매 버튼 `brand/buy_button_s.png` → 상품 `buyUrl`
- **버튼 2개가 본문의 맨 마지막.** 버튼 뒤에 아무것도 넣지 않는다. 글자 링크도 넣지 않는다.
- 썸네일과 제품 사진은 본문에 넣지 않는다. (썸네일은 사람이 직접 맨 위에 올림)

## 5. 썸네일
- `python3 -I blog/tools/thumb.py blog/thumb_template.png <제품 이미지> <출력.jpg> "<1줄>" "<강조어>" "<나머지>"`
- 제품 이미지: `DB_img/Product/<productImageFile>`
- 1068x600이지만 가운데 600x600 정사각형으로 잘려도 제품과 문구가 안 벗어나게 스크립트가 맞춘다. 결과물을 Read로 열어서 직접 확인한다.
- 문구는 고정하지 않는다. 마케터 입장에서 그 상품과 시기에 맞춰 매번 새로 쓴다.
  - 목표는 네이버 검색 결과에서 0.5초 안에 "중국산 없는 ○○구나"가 읽혀서 클릭하게 만드는 것. 가장 직관적인 문구가 우선이다.
  - 2줄 구성: 1줄(흰색) + 2줄(노랑 강조어 + 흰색 나머지). 강조어는 검색자가 찾는 제품군 이름 그대로 짧게 (예: 고춧가루, 파스타 소스, 떡볶이 떡).
  - 예: `중국산 원료 없는` / `고춧가루` ` 소개`, `김장 전에 꼭 확인` / `국산 고춧가루` ` 원산지`, `원재료 국산 100%` / `떡볶이 떡` ` 찾았어요`
  - 한 줄 12자 안팎. 길면 글자가 작아지니 짧게 다듬는다. 사실과 다른 과장(최고, 1위, 100% 안전 등) 금지.
- 파일명: `썸네일_<id>.jpg`

## 6. 복붙 페이지 만들기·전달
1. 작업 폴더에 `body.html`, `title.txt`(제목 한 줄), `tags.txt`(태그 한 줄) 작성
2. `python3 -I blog/tools/build_page.py <레포 폴더> body.html title.txt tags.txt page.html "블로그 #<id> <제품군>"`
3. Artifact 도구로 `page.html` 발행 (icon: `copy`, description: 한 문장)
4. SendUserFile로 썸네일 전달 (status: proactive)
5. 마지막 메시지(SendUserMessage)는 짧게: 오늘 상품명, 고른 이유 한 줄, 제목. 끝.
